# Do It Up, Bro

Maximize useful quality and throughput from available capacity: spend inference on independence, hard reasoning, execution, and falsification. Do not maximize token consumption.

## Start

When invoked as a host command, trailing arguments are the goal and may include
`--campaign` or `--federate`; these select protocol modes, not shell commands.

Interpret `Do it up, Bro: <goal>` as authorization to delegate substantial independent work within that goal. Use actual native subagents when available; never describe sequential role-play as independent agents. This instruction explicitly requests delegation where it creates value. Preserve the user's task scope, permission boundaries, budget, and stopping instructions.

Read `references/host-adapter.md` if installed. It describes the current host, not universal guarantees. If absent, inspect the host's available tools and help; use supported primitives and disclose missing capabilities. Do not invent flags, models, teams, or effort controls.

Shared skill directories may expose a bundle installed for another host. Verify that the adapter matches the actual host before using its instructions; otherwise detect current capabilities and use the applicable adapter or native help.

Choose native mode by default. For `--campaign`, read [protocol.md](references/protocol.md) for milestone state and recovery. For `--federate`, read [federation.md](references/federation.md) before launching anything.

## Lifecycle

1. **Triage:** Identify acceptance criteria, uncertainty, independent axes, objective checks, dependencies, and possible write conflicts. A small task may need only one agent.
2. **Scout:** Delegate bounded discovery across different files, facts, hypotheses, and test surfaces. Read [routing.md](references/routing.md) when selecting roles and capacity.
3. **Tournament:** Where credible competing approaches exist, obtain independent candidates without sharing a favored answer. Skip when alternatives offer little value.
4. **Adjudicate:** Judge candidates against requirements and evidence. Objective checks outrank votes; shared assumptions can produce shared errors.
5. **Execute:** Assign file ownership or isolated worktrees and run dependency-safe waves. Keep integration with one owner.
6. **Attack:** Give a fresh reviewer the result, requirements, and evidence needed to find counterexamples. Use [verification.md](references/verification.md) for consequential claims or changes.
7. **Repair:** Turn demonstrated failures into scoped corrections and rerun affected checks.
8. **Converge:** Apply [convergence.md](references/convergence.md). Complete acceptance checks, resolve material objections, and stop when another wave has little expected value.
9. **Synthesize:** Deliver the result, verification, and consequential uncertainty. Omit worker transcripts and manufactured consensus.

Keep the director's context small: retain decisions, dependencies, evidence pointers, and unresolved issues. Delegate raw logs and broad exploration; return concise findings with artifact paths. For multi-wave work, read [protocol.md](references/protocol.md) and persist enough state to recover.

`Spare no expense, Bro.` widens credible search, increases independent verification, and raises reasoning depth where useful. It never means unlimited spending, quota bypass, redundant clones, or expanded external authority.
