# Shared Codex / Antigravity project adapter

This project-local DUB bundle is intentionally shared by Codex and Antigravity,
which both discover `.agents/skills/do-it-up-bro`. Select only the adapter for
the actual host running this conversation:

- OpenAI Codex: read [codex-host-adapter.md](codex-host-adapter.md).
- Google Antigravity CLI (`agy`): read [agy-host-adapter.md](agy-host-adapter.md).

Do not combine their tool names, effort levels, permissions, or limits. If a
different host discovers this shared directory, use its native DUB installation
or inspect its actual tools; neither linked adapter governs another host.
